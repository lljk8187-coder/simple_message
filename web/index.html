选择一个会话

添加账号

需要一个已登录的 tiktok.com 会话 cookie。在浏览器里打开 devtools → Application/存储 → Cookies → https://www.tiktok.com，全选复制； 或从任意一个发往 tiktok.com 的请求里复制 Cookie 请求头。 必须包含 sessionid。

高级：发送凭据（只读可不填）

两种方式任选其一。档位 B（推荐）：填 ticket + 私钥，服务端本地签名， 不受捕获的头过期影响；档位 A：只填下面两个 guard 头，直接复用捕获值。 ts_sign 会自动从 guard 头里提取，不需单独填。

收割凭据

发消息需要的 ticket 和私钥只在页面签名的那一瞬间存在于浏览器内， 服务端拿不到。下面这个脚本把它们取出来回传到这里，省掉手工抄写。 每换一次账号或重新登录，做一遍即可。

1
在已登录的 TikTok 页面运行脚本
打开 tiktok.com（私信页最好）→ F12 → Console → 粘贴回车 → 然后发一条消息触发签名。页面右下角会出现一个浮层显示捕获进度。
2
把凭据贴回来 · 等待中
浮层里三项都变成 captured 后，点「复制凭据 JSON」，粘贴到这里。
（tiktok.com 的 CSP 会拦掉页面往 localhost 的自动回传，所以这一步是手动的。）
3
补一次 cookie 并保存
cookie 里的 sessionid 是 HttpOnly，页面脚本读不到，所以这一步 需要手工复制一次：devtools → Application → Cookies → https://www.tiktok.com 全选复制。
